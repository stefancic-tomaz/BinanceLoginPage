# Binance – Prijavni in registracijski obrazec

Šolski projekt, pri katerem sem izdelal prijavni in registracijski obrazec po vzoru spletne platforme **Binance**. Glavni cilj naloge je bil čim natančneje poustvariti videz izvirne spletne strani ter uporabiti znanje spletnega programiranja v praksi.

Projekt je namenjen izključno izobraževalnim namenom in ni povezan z uradno platformo Binance.

## O projektu

Pri izdelavi sem se osredotočil na natančnost oblikovanja, preglednost uporabniškega vmesnika in pravilno strukturo spletne strani.

Glavni cilji projekta:

- Čim natančnejša poustvaritev izvirnega obrazca.
- Izdelava prijavne in registracijske strani.
- Uporaba sodobnih tehnik oblikovanja s CSS.
- Prilagoditev spletne strani različnim velikostim zaslonov.
- Pregledna organizacija in berljivost izvorne kode.
- Implementacija osnovne interaktivnosti obrazcev.

## Uporabljene tehnologije

| Tehnologija | Namen |
|---|---|
| HTML5 | Struktura spletne strani in obrazcev |
| CSS3 | Oblikovanje in odzivna postavitev |
| JavaScript | Interaktivnost in preverjanje podatkov |
| Git & GitHub | Verzijski nadzor in dokumentacija |

## Funkcionalnosti

Projekt vključuje:

- **Prijavni obrazec** – vnos e-poštnega naslova in nadaljevanje prijavnega postopka.
- **Registracijski obrazec** – ločena stran za prikaz registracije.
- **Potrditveno kodo** – demonstracijski korak preverjanja uporabnika.
- **Odzivno oblikovanje** – prilagajanje postavitve različnim zaslonom.
- **Temno barvno shemo** – oblikovanje po vzoru izvirne platforme Binance.

## Testni podatki

Za preizkus demonstracijskega prijavnega postopka so na voljo naslednji podatki:

| Podatek | Vrednost |
|---|---|
| E-poštni naslov | `test@gmail.com` |
| Potrditvena koda | `123456` |

Testni podatki so namenjeni izključno predstavitvi delovanja obrazca. Prijava v dejanski uporabniški račun Binance ni mogoča.

## Pridobljeno znanje

Med izdelavo projekta sem utrdil znanje HTML, CSS in JavaScript ter pridobil dodatne izkušnje pri oblikovanju spletnih obrazcev.

Poseben poudarek je bil na uporabi **Flexbox**, CSS-medijskih poizvedb (`@media`), pravilnem razporejanju elementov in zagotavljanju doslednega videza na različnih napravah.

## Možne nadgradnje

Projekt bi bilo mogoče v prihodnosti izboljšati z naprednejšo validacijo podatkov, dodatnimi animacijami, izboljšano dostopnostjo in razširjenimi demonstracijskimi funkcionalnostmi.
